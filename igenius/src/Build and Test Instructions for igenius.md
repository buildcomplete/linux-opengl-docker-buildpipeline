# Build and Test Instructions for igenius

This document provides instructions on how to build the `igenius` application and run the newly added unit tests. The changes were made to be minimal and integrate with the existing `premake5` build system.

## Summary of Changes

To integrate unit testing, the following changes were made:

1.  **New Test Directory**: A new directory `src/tests` was created to hold all unit test files.

2.  **Enhanced Plain C++ Test Framework**: A simple, plain C++ test framework was created in `src/tests/test_main.cpp`. This approach includes colored output (green for PASS, red for FAIL) and detailed failure reporting with actual vs expected values.

3.  **Updated Build Configuration**: The `build/premake5.lua` file was modified to include a new `igenius_tests` project. This project is configured to build a separate executable for running the tests.

4.  **Test Runner Scripts**: Since the `Makefile` is generated by premake5, custom shell scripts were created to build and run tests easily.

## How to Build

To build the project, you will need to have `make` and a C++ compiler installed. The following commands should be run from the root of the `igenius` directory.

### Build the Main Application

To build the main `igenius` application, run the following command:

```bash
make config=debug_x64 igenius
```

This will create the `igenius` executable in the `bin/Debug/` directory.

### Build the Unit Tests

To build the unit test executable, run the following command:

```bash
make config=debug_x64 igenius_tests
```

This will create the `igenius_tests` executable in the `bin/Debug/` directory.

### Build Everything

To build both the main application and the unit tests, you can use the `all` target:

```bash
make config=debug_x64 all
```

## How to Run the Tests

### Using the Test Runner Scripts (Recommended)

The easiest way to build and run tests is using the provided shell scripts:

#### Run Debug Tests
```bash
./run_tests.sh
```

#### Run Release Tests
```bash
./run_tests_release.sh
```

These scripts will automatically build the tests (if needed) and then run them, providing clear feedback if the build fails.

### Manual Test Execution

After building the `igenius_tests` executable, you can also run the tests manually:

```bash
# Build tests first
make config=debug_x64 igenius_tests

# Then run them
./bin/Debug/igenius_tests
```

For release mode:
```bash
# Build tests first
make config=release_x64 igenius_tests

# Then run them
./bin/Release/igenius_tests
```

## Test Framework Features

The testing framework includes:

- **Colored Output**: PASS results in green, FAIL results in red
- **Detailed Failure Reporting**: Shows expected vs actual values when tests fail
- **Multiple Test Functions**:
  - `test_assert()` for boolean conditions
  - `test_equals()` for value comparisons with detailed failure output
  - `test_equals_string()` for string comparisons with proper formatting

## Important Notes

- The `Makefile` in the root directory is **generated by premake5** and should not be manually edited
- Any changes to the build configuration should be made in `build/premake5.lua`
- After modifying `premake5.lua`, regenerate the build files with: `cd build && ./premake5 gmake2`
- The test runner scripts handle building automatically, so you typically don't need to run make commands manually
